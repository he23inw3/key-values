概要
==

metadata (アプリケーションメタデータ)

マスターパスワード検証用トークン（`verification`）やパスワードヒント（`hint`）などのアプリケーション設定・制御用メタデータを管理するキー・バリューストアテーブルです。

テーブル定義
======

| カラム名 | 型 | モード | 説明 |
| :--- | :--- | :--- | :--- |
| `key` | TEXT | REQUIRED | メタデータキー (主キー, 例: `verification`, `hint`) |
| `value` | TEXT | REQUIRED | メタデータ値 (暗号化トークン文字列またはヒントテキスト) |

一意キー
======

| No | シーケンス | カラム名 | 説明 |
| :--- | :--- | :--- | :--- |
| 1 | 1 | `key` | 主キー (PRIMARY KEY) |
