概要
==

メインアカウント管理画面 (MainWindow.xaml)

アプリケーションのアカウント一覧表示・インクリメンタル検索・詳細情報の閲覧・新規登録・編集・削除、パスワード自動生成ツール、CSV一括インポート、データベースのバックアップ・復元、テーマ切替を統括・管理するメイン画面です。

主要機能一覧
======

- **🔍 アカウント一覧 & インクリメンタル検索 (AccountListPanel)**: 登録済みアカウントの一覧表示、キーワード入力（サービス名・ログインID）による即時フィルタリング。
- **📝 アカウント詳細・編集・新規追加 (AccountDetailPanel)**:
  - アカウントの新規作成・編集・削除。
  - パスワード等のマスク表示切り替え (`👁️`)。
  - ワンクリッククリップボードコピー（ログインID / パスワード）。
- **🎲 パスワード自動生成ツール (PasswordGeneratorViewModel)**:
  - 桁数指定 (4〜64文字)、使用文字種（英小文字、英大文字、数字、記号）のカスタマイズ。
  - 生成パスワードのワンクリックコピーおよびアカウントフォームへの適用。
- **📥 CSV一括インポート**: 外部 CSV ファイルからのアカウント一括取り込み機能 (`ImportCsvCommand`)。
- **💾 バックアップ & 🔄 データ復元**:
  - `SaveFileDialog` による暗号化データベースファイルの別名出力保存 (`BackupCommand`)。
  - `OpenFileDialog` による既存バックアップファイルからの安全なデータ復元 (`RestoreCommand`)。
- **🛡️ Windows Hello 自動サインイン切替**: ツールバーからこのPCでの Windows Hello 生体認証・自動ログインの有効/無効を切替。
- **🔔 ステータス通知バナー**: 操作完了時（保存・削除・コピー・バックアップ等）のトーストメッセージ表示。

画面構成・レイアウト
======

| コンポーネント・領域名 | UI要素 | 説明・役割 |
| :--- | :--- | :--- |
| **TopToolbar** (上部) | UserControl | アプリロゴ、一括追加、バックアップ、データ復元、Windows Hello設定、テーマ切替ボタン |
| **AccountListPanel** (左側) | UserControl / ListBox | インクリメンタル検索ボックス、アカウントリスト、新規アカウント追加ボタン |
| **AccountDetailPanel** (右側) | UserControl / Grid | アカウント詳細入力フォーム（サービス名、ID、パスワード、URL、メモ）、コピーボタン、削除・保存ボタン |
| **PasswordGenerator** (右側内包) | Expander / Grid | パスワード自動生成ツール（桁数スライダー、オプションチェックボックス、生成・コピーボタン） |
| **Status Bar** (下部) | Border / TextBlock | 処理結果（成功・警告・エラー）のステータスメッセージ表示およびオフライン暗号化保護状態アイコン |

処理フロー・イベント動作
======

1. **アカウント選択および新規作成**
   - リストからアイテム選択時: `SelectedEntry` が更新され、右側パネルにデータがバインド表示。
   - 「新規アカウント追加」ボタン押下時: 空の新規 `AccountEntry` オブジェクトが生成され編集モードに移行。

2. **アカウントの保存・更新**
   - 「保存」ボタンクリック時: 入力チェック（サービス名・ID等の必須判定）後、`Save` メソッドを呼び出し。
   - 暗号化サービス (`CryptoService`) を使用して入力内容をマスターパスワードで暗号化し、SQLite データベース (`accounts` テーブル) に保存。
   - ステータスバナーに「アカウント情報を保存しました。」と成功通知を表示。

3. **バックアップ & 復元**
   - **バックアップ**: `SaveFileDialog` を表示し、指定した `.db` / `.bak` パスへ現行データベースを複写保存。
   - **復元**: `OpenFileDialog` で復元元ファイルを選択。暗号化検証を行った上でデータベースを復元・一覧を自動再読み込み。
