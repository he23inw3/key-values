概要
==

マスターパスワード設定・認証画面 (MasterPasswordWindow.xaml)

アプリケーション起動時にデータベースの復元・復号に必要なマスターパスワードの初回登録、および2回目以降のサインイン照合、Windows Hello 自動サインイン設定、パスワードヒント表示、データベースリセットを管理・制御する画面です。

主要機能一覧
======

- **🔒 サインイン認証 (Unlock Mode)**: 入力されたマスターパスワードでデータベース内の暗号化メタデータを照合し、正しければデータベースを開いてメイン画面へ遷移。
- **🔑 初回マスターパスワード登録 (Setup Mode)**: データベース初期作成時に新規マスターパスワードおよび確認用パスワードを設定・保存。
- **💡 パスワードヒント**: 登録時に設定されたパスワードヒントを「ヒントを表示」リンクより安全に展開表示。
- **🛡️ Windows Hello 生体認証 / 自動ログイン**: 画面上のチェックボックス選択時、Windows DPAPI / Windows Hello 生体認証を用いた自動サインイン機能を設定。
- **⚠️ データベースリセット**: マスターパスワード喪失時に確認ダイアログを経てデータベースおよび設定ファイルを削除・リセット。
- **🌙 テーマ切り替え**: タイトルバー右上のボタンによりライト/ダークテーマを動的に切替。

処理フロー・イベント動作
======

1. **画面初期化処理 (`Loaded`)**
   - データベースファイルが存在するか確認 (`SqliteAccountRepository.FileExists()`)。
   - データベースが存在しない場合は**初回登録モード (Setup Mode)** として起動。存在する場合は**サインインモード (Unlock Mode)** として起動。
   - 自動ログインが有効な場合、DPAPI等からパスワードをロードして自動照合・メイン画面へ遷移。

2. **「開く / 設定」ボタンクリック (または PasswordBox で Enter 押下)**
   - **Unlock Mode の場合**:
     - `VerifyMasterPassword(inputPassword)` を呼び出し。
     - 正しい場合: ダイアログ結果を `true` として画面を閉じ、メイン画面を起動。
     - 誤っている場合: エラーメッセージ「マスターパスワードが正しくありません」を表示。
   - **Setup Mode の場合**:
     - パスワード入力チェック（空チェック、確認用入力の一致チェック）。
     - `RegisterVerification(newPassword)` で暗号化トークンをメタデータに保存。
     - ヒントが入力されていれば `SavePasswordHint(hint)` を実行。
     - Windows Hello / 自動ログインにチェックがあれば `EnableAutoLogin(newPassword)` を呼び出し。
     - 登録完了後、メイン画面へ遷移。

3. **「パスワードを忘れた場合（リセット）」ボタンクリック**
   - 警告メッセージボックスを表示。確認後、`ResetDatabase()` を呼び出して DB ファイルを削除し、Setup Mode に切り替え。
