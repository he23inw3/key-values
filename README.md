# KeyValues - ローカルアカウント管理ツール

AmazonやGoogle等のログイン情報（ID/パスワード）を、インターネットに接続せずWindows PC上で安全に一括管理するポータブルパスワードマネージャーです。

---

## 特徴

1. **完全オフライン動作**: 外部ネットワーク通信は一切行わず、データはローカルPC内のみで完結します。
2. **インストーラー不要 (ポータブル)**: 単一の `.exe` 実行ファイルと暗号化されたローカルデータベース（`data/key-values.db`）のみで動作します。USBメモリ等で他のPCへアプリ一式をコピーするだけで移行可能です。
3. **AES-256暗号化による安全保護**: 個々の機密情報（ログインID、パスワード、URL、メモ）は、マスターパスワードとPBKDF2（100,000回反復）で生成された暗号キーを使ってAES-256で個別に暗号化され、データベースに保管されます。
4. **Windows Hello 連携（自動サインイン）**: 
   - デバイスに設定されている Windows Hello（指紋、顔、PIN）による自動ロック解除に対応。
   - マスターパスワード自体を Windows DPAPI で暗号化してローカルに保護し、次回から生体認証やPINだけで瞬時にログインできます。
   - コピー先（別PCや別アカウント）では自動ログインは無効化され、手動でのマスターパスワード入力を求められるため、ポータブル性を崩しません。
5. **パスワード自動生成 & クリップボード安全保護**:
   - 強固なパスワードをワンクリックで生成して適用できます。
   - パスワードをコピーした際、20秒後に自動的にクリップボードから消去して漏洩を防ぎます。
6. **紛失対策（ヒント＆データベースリセット）**:
   - パスワード設定時にヒント（任意）を登録でき、ロック解除画面で確認できます。
   - 万が一パスワードを完全に紛失した場合、データを物理削除して最初からやり直せる「データリセット」機能も備えています。

## システム要件

- **OS**: Windows 10 Version 2004 (Build 19041) 以降 / Windows 11
- **ランタイム**: .NET 10.0 (※自己完結型パブリッシュを行っているため、ランタイム未インストールのPCでも実行可能)

---

## EXEの実行方法およびビルド手順

### 1. 単一EXEファイル（ポータブル版）の生成
自己完結型（Self-Contained）の単一実行ファイルをパブリッシュする場合、以下のいずれかの方法で行います。

#### PowerShell ビルドスクリプトを使用（推奨）
既存のビルドキャッシュ（`bin/`, `obj/`）を安全にクリーンアップした上でパブリッシュします。

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

### 2. 生成されたEXEの配置と起動
ビルド成功後、以下の出力フォルダに単一の `KeyValues.exe` が生成されます。

```
bin/Release/net10.0-windows10.0.19041.0/win-x64/publish/KeyValues.exe
```

- `KeyValues.exe` を任意のフォルダ（またはUSBメモリ）に配置し、ダブルクリックで直接起動できます。

## 📁 データファイルと管理方法

本アプリのデータや設定ファイルはすべて、`KeyValues.exe` と同一階層（またはカレントディレクトリ）の **`data/` ディレクトリ** 内で自動管理されます。

```
KeyValues/
  ├── KeyValues.exe            # アプリ本体
  └── data/                    # 自動作成されるデータフォルダ
        ├── key-values.db      # 暗号化SQLiteデータベース (必須)
        ├── autologin.dat      # DPAPI自動サインイン設定ファイル
        └── settings.cfg       # UI設定ファイル (テーマ等)
```

### 1. データベースファイル (`data/key-values.db`)
- アカウント情報や暗号化用検証メタデータが保管される暗号化 SQLite データベースです。
- **ポータブル移行方法**: `KeyValues.exe` と `data/` フォルダをそのまま別のPCやUSBメモリにコピーするだけで、データを保持したまま移動・利用できます。

### 2. 自動ログインファイル (`data/autologin.dat`)
- Windows Hello や自動サインインを有効化した際、Windows DPAPI (Data Protection API) でログインユーザー固有の暗号キーを使ってマスターパスワードを暗号化保存したファイルです。
- **セキュリティ仕様**: このファイルは「暗号化したPCかつ同一ログインユーザー」でのみ復号可能です。別のPCや別ユーザー環境へコピーされた場合は自動的に復号が拒否され、手動でのマスターパスワード入力画面に安全にフォールバックします。
- **解除方法**: アプリ画面から自動サインインをオフにするか、`data/autologin.dat` を直接削除することで解除できます。

### 3. 設定ファイル (`data/settings.cfg`)
- ダークモード/ライトモードなどの表示設定が保存されます。削除された場合はデフォルト（ダークモード）で自動再生成されます。

### 4. バックアップと復元 (Backup & Restore)
- アプリ内のメニューから現在のデータベースを別ファイル（例: `backup_2026.db`）へコピーバックアップできます。
- バックアップから復元する際は、現在のマスターパスワードとの照合が行われ、正しく一致した場合のみ安全に復元されます。

### 5. データベースリセット (初期化)
- ロック解除画面の「データベースリセット」ボタン、または `data/` ディレクトリを直接手動削除することで、すべての登録データと設定を消去して初期登録状態に戻せます。
